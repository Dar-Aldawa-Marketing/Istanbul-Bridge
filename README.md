# Istanbul-Bridge

Static Bridge symposium website, adapted from Control. No build or npm installation required.

## Publish
1. Extract this ZIP. Upload the contents of this folder to the root of the **Istanbul-Bridge** repository, so `index.html` is at the repository root. Include `assets`, `manus-storage`, `404.html`, `manifest.webmanifest` and `.nojekyll`.
2. In GitHub Settings → Pages, choose **Deploy from a branch**, branch **main**, folder **/ (root)**.
3. Open https://dar-aldawa-marketing.github.io/Istanbul-Bridge/

## Content
- 13–16 October 2026; social programme from the supplied spreadsheet.
- 14 October: registration 09:30–10:00; Bridge Scientific Symposium 10:00–12:30, M24.
- All seven product marks and Bridge identity from the supplied artwork.
- Speaker biographies and detailed lectures are intentionally hidden pending new source material.
- Contact details are retained from the reference Control website; no new contact list was supplied.
- The original Day 2 lunch/free-time overlap is preserved and noted.
- Programme times are local; calendars use Europe/Istanbul (the supplied Amman flights share the same UTC offset in October 2026).
- Agency-only operational instructions are not displayed to guests.
- Weather, exchange rates, Google Fonts, maps and messaging require an internet connection. All event images and application files are included.
